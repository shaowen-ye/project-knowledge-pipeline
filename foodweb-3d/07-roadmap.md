## B. 三条论文线 / Three publication lines（全覆盖）

### 论文线 1 · 理论统一 / Theory unification
- **贡献**：把**蜂腰控制 + 级联**形式化嵌入 **meta-生态系统**空间通量模型；检验流量调控与禁渔是否使受调控水库在上行/下行/蜂腰机制间迁移、并沿级联传播。
- **目标期刊**：*Nature Ecology & Evolution* / *Ecology Letters*（概念/理论导向）。
- **数据需求**：相对低——可先以模型/理论 + 少量长江参数化演示；定位于装配规则/复杂性–稳定性前沿（[04](04-theory.md) §6）。
- **里程碑**：M1 数学骨架（patch×流+控制指数）；M2 长江参数化的机制迁移演示；M3 稿件。
- **风险**：理论新颖性须超越"把已知概念放一起"——需给出**可检验的新预测**（如某流量阈值触发机制切换）。

### 论文线 2 · 方法 + 软件 / Method + software
- **贡献**：开源 3D 交互、时空耦合、不确定性感知框架本身（L1–L3 + L2 交换格式）——Craig & Link 2023 意义上的"战术化"决策支持工具 / 生态数字孪生方向。
- **目标期刊**：*Methods in Ecology & Evolution* / *Ecological Modelling*。
- **数据需求**：中——需一个可复现 case（单水体）证明端到端可用 + 与既有工具对比。
- **里程碑**：M1 L2 格式 v1.0 + 适配器（≥2 引擎）；M2 3D 渲染层 + 不确定性可视化；M3 可复现 case + 软件论文 + 开源发布（含 DOI/Zenodo）。
- **风险**：软件类顶刊要求**他人可采用**——需文档、测试、包发布、真实 case，不能停在 demo。

### 论文线 3 · 大综合 / 自然实验 / Grand synthesis · natural experiment
- **贡献**：十年禁渔前后多水体食物网**网络变化** + 机理模型**预测**其复杂度/关键种迁移；含无人闭合的**"产卵信号 × 食物网耦合"**——生态调度洪水脉冲如何作为补给传导、增温是否使四大家鱼产卵信号与固定调度错配。
- **目标期刊**：*Fish and Fisheries* / *Global Change Biology* / *PNAS*。
- **数据需求**：高——需长江多水体禁渔前后监测（鱼类、同位素/eDNA、水文、调度记录）。**数据获取是最大门槛**。
- **里程碑**：M1 多水体禁渔 before/after 网络分析（可先用已发表数据综合）；M2 机理模型复现观测到的复杂度/关键种迁移（样本外验证）；M3 产卵信号×食物网×增温耦合预测；M4 稿件。
- **风险**：数据可得性与授权；自然实验缺对照——需以多水体/多时点与机理模型互证弥补。

## C. 论文线依赖与建议顺序 / Sequencing

```
阶段1(原型) ─┬─→ 论文线2(方法+软件)  ← 最先可独立完成，产出工具供 1、3 复用
             │
阶段2(耦合)  ─┼─→ 论文线3(自然实验)  ← 依赖数据 + 阶段2耦合模型
             │
             └─→ 论文线1(理论)       ← 可较早并行(数据需求低)，但"可检验新预测"需框架支撑
```

**建议**：先攻**论文线 2**（工具即基础设施，风险可控、他用价值高），并行推进**论文线 1**（数据需求低），**论文线 3** 随阶段 2 数据到位再冲最高层。

---

## D. 里程碑级风险与缓解 / Cross-cutting risks

| 风险 | 缓解 |
|---|---|
| 数据获取（尤其论文线 3） | 先用已发表数据做综合；同步申请监测数据/合作 |
| 范围过大失焦 | 以 L2 交换格式为收敛枢纽；每论文线独立可交付 |
| 软件维护负担 | 包裹既有引擎而非重造；开源+CI+文档从阶段 1 起 |
| 理论新颖性不足 | 论文线 1 必须给可证伪的新预测，而非概念拼合 |
| 不确定性被审稿质疑 | 从阶段 1 起把不确定性作默认贯穿量（[05](05-gaps-difficulties.md) §1） |
