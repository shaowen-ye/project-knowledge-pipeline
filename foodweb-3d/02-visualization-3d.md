# 02 · 3D / 交互可视化全景与空白 / 3D & Interactive Visualization Landscape and the Gap

> 食物网与生态系统可视化的现状，及**本项目赖以立足的真空白**。结论：静态网络渲染器优秀、物理模拟器优秀、营养模拟器优秀——但**没有把"运行中、空间显式、时间动画、不确定性感知"的食物网融进一个交互 3D 界面的工具**。

---

## 1. 通用网络工具（非生态专用）

| 工具 | 类型 | 说明 |
|---|---|---|
| **Gephi** | 桌面 2D | 交互布局/探索（Bastian et al. 2009） |
| **Cytoscape** | 生物网络平台 | Shannon et al. 2003；插件生态丰富 |
| **R `igraph` / `ggraph` / `tidygraph`** | 脚本 2D | 分析+静态出图 |
| **R `visNetwork` / `networkD3`** | 交互 HTML | 基于 vis.js / D3 的可交互小部件 |
| **R `threejs` / `network3d`** | WebGL 3D | 3D 散点/图，轻量但功能有限 |
| **Python `networkx` + Plotly** | 脚本/交互 | 通用图分析+交互出图 |
| **D3.js / three.js / sigma.js / Cytoscape.js** | Web 定制 | 自建 Web 应用的底层库（**本项目 3D 渲染层候选**） |

通用工具能画网络，但**不懂营养级、不懂流量方向与量级、不懂空间水体、不懂时间轴**——需自建领域语义层。

## 2. 生态专用工具

| 工具 | 能力 | 局限 |
|---|---|---|
| **Cheddar**（R） | 群落分析+可视化，含体重/丰度；标准静态食物网图（营养高度、PDMR） | 静态、非交互。Hudson et al. 2013, *MEE* 4:99–104（doi:10.1111/2041-210X.12005） |
| **Network3D / "Webs on the Web"** | 用第三维（**营养级作垂直轴**）拆解稠密网络 | 无权重、超 ~40 节点即吃力、已不再公开维护。Yoon, Williams, Martinez et al. ~2004–2005。**历史重要：营养级 z 轴的思想源头** |
| **Foodweb3D / GlobalWeb** | 关联全球食物网数据库的 3D 浏览器 | 浏览已发表网，非模拟耦合 |
| **Pawluczuk et al. 2023** | 三种互补 D3/Web 视图：热图、交互图、**动画流网络** | **最接近动态、加权、交互的食物网可视化**，但仍是 **2D**、且**不与运行中模拟或空间场耦合**。*MEE*（doi:10.1111/2041-210X.13839） |
| **VisuaLIT / LIM 可视化** | LIM 流网可视化 | 锁定宿主软件 |
| **EwE 内置 Flow diagram / Ecospace map** | 模型专用输出 | 锁定 EwE，非通用、非 3D 动态 |

## 3. 真空白：4 点 / The genuine gap（本项目的立身之本）

没有成熟、通用、开源的工具，能做到**3D 交互 + 动态动画 + 时空数据耦合**的食物网模拟可视化。具体不存在的集成产品能力：

1. **网络上的时间动画流** —— 几乎所有食物网可视化只画静态拓扑；少数"动态"工具动画的是**布局**而非**状态**（生物量、通量、营养位置随模拟时间轴演化 + 时间滑块 scrubber）。
2. **网络与物理/空间域耦合** —— 无标准工具把营养网络叠加在**真实 3D 水体**（湖泊测深 / 河段 / 分层水柱）上，让流量与节点状态响应水动力、温度、深度——即把 GLM-AED / CE-QUAL-W2 / Delft3D 的物理场绑定到动画化的 EwE/mizer/LIM 网络于同一视图。
3. **加权、可扩展、带不确定性的 3D** —— Network3D 的"营养级 z 轴"承诺从未成熟为可维护、加权、WebGL、超数十节点仍清晰、且能渲染**分布**（LIM/贝叶斯流不确定性）而非单一边的工具。
4. **模型无关摄入** —— 各引擎（EwE、mizer、OSMOSE、Atlantis、GLM-AED、LIM）各出各的格式；没有通用交换格式/渲染器，可视化被逐模型重造。

**一句话**：领域有优秀的静态网络渲染器、优秀的物理解析模拟器、优秀的营养模拟器——却**没有把"运行中、空间显式、时间动画、不确定性感知"的食物网融进一个交互 3D 界面的东西**。这对水生系统是真实、可辩护的产品/研究空白。

---

## 4. 对本项目的启示 / Implications

- **可复用的思想与库**：Network3D 的营养级 z 轴、Pawluczuk 2023 的动画流范式、three.js/WebGL 渲染层、LIM 的流分布——**要件都在，从未被融合**（这是"集大成"的可行性依据）。
- **产品定位**：本项目 3D 渲染层 = 领域语义（营养级 z 轴 + 加权有向流 + 不确定性带）× 时间轴 scrubber × 空间水体底图 × 情景开关。详见 [06-framework-design.md](06-framework-design.md) 的"3D 渲染层"。
- **发表价值**：可视化框架本身即 *Methods in Ecol. & Evol.* / *Ecological Modelling* 可引用贡献（见 [07-roadmap.md](07-roadmap.md) 论文线 2）。
