# 14 · 空间控制机制模型与相图 / Spatial Control-Regime Model & Phase Diagram

> 论文线 1（[11](11-paper1-theory-plan.md)）的**理论核心开发**：把跨系统补给做成**动力学强耦合**（不再只是可视化弧），并用一个极简正则 meta-生态系统模块产出**控制机制相图**（Fig 2）与**补给梯度上的机制迁移/阈值**（Fig 3）。实现见 `prototype/theory/`。**演示级理论模块，非定量预报。**

---

## 1. 目的 / Purpose

检验命题 T1–T3（[11](11-paper1-theory-plan.md) §1）：控制机制（上行/下行/蜂腰）是**局域互作强度 α × 跨系统补给 σ**的涌现相态；存在临界连通度阈值 σ*(α)；α 与 σ 是可迁移系统于机制间的**管理杠杆**（α≈捕食压/禁渔↔捕捞；σ≈水文连通/流量调控）。

---

## 2. 模型 / Model（`prototype/theory/metaecosystem.js`）

**结构**：3 个 patch（河→库→湖）链式连接，每 patch 一条 4 层垂直链 **A→H→F→P**（生产者→植食者→**饵料层**→捕食者）。焦点 = 库区（patch 1）。

**patch 内动力学**（Lotka-Volterra / 生物能量式，α 缩放上层捕食）：
```
dA = rA·A(1−A/K) − a_AH·H·A
dH = e·a_AH·H·A − mH·H − (α·a_HF)·F·H
dF = e·(α·a_HF)·F·H − mF·F − selfF·F² − (α·a_FP)·P·F
dP = e·(α·a_FP)·P·F − mP·P
```
- **α**（局域互作强度）缩放上层（捕食侧）攻击率 a_HF、a_FP —— 改变**相对**结构（捕食压），非均匀缩放（后者只重标生物量、不改无量纲控制结构，早期尝试已验证此陷阱）。
- **selfF·F²**（饵料层自限）是关键：使 F 成为可自调节的**通量闸门**，为蜂腰控制提供机制。

**跨系统流**（σ 缩放，**动力学强耦合**——进入 ODE，非可视化）：
- 下行物质漂流：R/A 的生产者顺流 q→q+1（`driftA`×σ）；
- 消费者双向扩散：H、F、P 相邻 patch 间（`disp`×σ），**F 扩散最强**（作空间闸门）。

**平衡**：RK4 积分至稳态（`equilibrium`）。

---

## 3. 控制机制分类 / Classifier（per-capita 控制率，量纲一致可比）

对焦点 patch 的枢纽**饵料层 F**，分解其调节的三条 per-capita 速率（单位 1/时间，天然可比）：

| 机制 | per-capita 速率 | 含义 |
|---|---|---|
| **下行 top-down** | `α·a_FP · P` | 捕食者对饵料层的人均捕食压 |
| **蜂腰 wasp-waist** | `2·selfF · F` | 饵料层密度依赖自调节（闸门） |
| **上行 bottom-up** | `mF + σ·disp_F·0.55` | 基线周转 + 跨系统补给驱动的通量 |

机制 = 三者中最大者。三率同量纲、各由一个 α/σ 可动的机制驱动——避免了早期"弹性尺度不可比、下行恒赢"的问题（诊断见开发记录 D-007）。

## 4. 结果 / Results（`phase-diagram.js` → `theory-figures.json`）

**Fig 2 · 相图**（40×40 网格，`prototype/theory-figures.html`）：同一 meta-生态系统在三区迁移——
- **蜂腰**（低 α、低 σ）：弱捕食 + 隔离，饵料层自调节主导；
- **下行**（高 α）：强捕食压，捕食者控制沿链级联；
- **上行**（高 σ）：强补给/连通，通量驱动；
- **捕食者崩溃**（极低 α）：捕食效率不足，P 灭绝（真实模型结局，单列）。

**Fig 3 · 补给梯度与阈值**：固定 α=1.05，随 σ 增大控制由**下行→上行**翻转，**临界阈值 σ*≈0.79**；且 **σ*(α) 随 α 右移**（0.7→0.38、1.05→0.79、1.6→0.94）——**预捕压越强，翻转到上行所需连通度越大**，即两杠杆**交互**（T2/T3 的量化）。本模块单稳态，未见滞后（`hysteresis` 探测：固定初值下 up==down；检测替代稳态需带状态延拓）。

## 4a. 边界解析 / Analytical boundaries

相图的区域边界正是**等控制率轨迹**（§3 三率两两相等），可写出解析条件：

- **下行 / 上行 边界**（td = bu）：
  `α·a_FP·P*(α,σ) = mF + 0.55·σ·disp_F`
  ⟹ `σ*(α) = ( α·a_FP·P*(α,σ*) − mF ) / ( 0.55·disp_F )`（隐式：P* 依赖 σ，须由平衡数值求解）。
- **蜂腰 / 下行 边界**（ww = td）：`2·selfF·F*(α,σ) = α·a_FP·P*(α,σ)`。
- **蜂腰 / 上行 边界**（ww = bu）：`2·selfF·F*(α,σ) = mF + 0.55·σ·disp_F`。

**定性推论**（与 Fig 3 的 σ*(α) 右移一致）：`σ*` 随 α 增大而增大——预捕压 α 越强，`α·a_FP·P*` 越大，需要越大的 σ 才能让 bottom-up 通量项追平，故翻转到上行所需连通度越高。这解析地解释了 Fig 3 的两杠杆交互。

Fig 2/4 中绘制的白/虚线 σ*(α) 即上述 td=bu 轨迹的数值解。

### 闭式准静态近似 / Closed-form quasi-static approximation（`prototype/theory/closed-form.js`）

对焦点 patch 的 4 层链逐方程求平衡（predator-controlled 分支）：

```
F* = mP / (e·α·a_FP)                          (捕食者钉住饵料层, top-down)
A* = ( mH + a_HF·mP/(e·a_FP) ) / (e·a_AH)      (α 抵消 → 常数)
H* = rA·(1 − A*/K) / a_AH                       (α 抵消 → 常数)
P* = ( e·α·a_HF·H* − mF − selfF·F* ) / (α·a_FP)
```

**验证**：σ=0（patch 隔离）时上式与数值平衡**精确吻合**（0.00% 误差，α∈{0.6,1.05,1.6,2.0} 逐组核验）。

**两个可引用的解析结论**：
1. **A\*、H\* 与 α 无关**（α 在植食者/生产者方程中抵消）——在捕食者控制区，**生产者与植食者生物量不随捕食压变化**，仅饵料层 F*∝1/α 与捕食者 P* 响应（经典 Oksanen 型剥削生态系统签名，从本模块涌现）。
2. 代入 td=bu 得 **σ*(α) = ( α·a_FP·P* − mF ) / (0.55·disp_F)**；因主导项 `e·a_HF·H*·α` 线性于 α，故 **σ* 随 α 近似线性上升**——解析地证实 Fig 3 的右移与两杠杆交互。

闭式 σ*(α) 在低 α 与数值网格吻合好（α=0.7:闭式 0.36 vs 网格 0.38），高 α 偏大（σ>0 的补给降低 td 的修正未含）——即这是**一阶（σ=0）解析界**；完整 σ 依赖仍由数值求解（[11](11-paper1-theory-plan.md) §7 T4 剩余项）。

## 5. 与管理/长江的映射 / Mapping to management

| 模型轴 | 管理含义 |
|---|---|
| α↑（捕食压/上层互作） | 禁渔恢复捕食者 → 强化下行；重捕耗竭捕食者 → 移向蜂腰 |
| σ↑（跨系统补给/连通） | 河湖连通、生态调度涨水 → 强化上行；大坝隔离/流量调控 → 削补给、移向下行 |
| σ*(α) 阈值 | 受调控水库处于相图何处、对干预如何响应的可检验预测（[11](11-paper1-theory-plan.md) Fig 4） |

> 这把大坝流量调控**理论化**为控制机制迁移的空间杠杆，正是论文线 1 相对 Cury（蜂腰）、Carpenter（级联）、Loreau（meta-生态系统）各自独立文献的统一贡献。

## 6. 局限 / Caveats

- **演示级正则模块**：4 层链 × 3 patch，参数经调参以产生清晰、可读、三区俱全的相图；非某一实测系统率定。
- 分类基于枢纽饵料层的 per-capita 控制率；替代定义（弹性/环路分析）会移动边界——正式稿应给多定义稳健性（[11](11-paper1-theory-plan.md) §8）。
- 单稳态：未含可能产生滞后的强非线性（如 Allee、多稳态）；滞后为理论预测项，需扩展模型检验。
- 蜂腰区较窄：真实蜂腰系统的参数窗口本就有限；图中为示意性区域。
